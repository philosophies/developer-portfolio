REACT / VITE / MAINTENANCE CASE STUDY

Smart-Brain modernization

An isolated migration prototype for an earlier full-stack project. It separates validation and bounding-box rendering from a detector adapter so behavior can be tested without external credentials.

THE PROBLEM

Modernize the seams before reconnecting the system.

The reviewed legacy project has older dependencies and routes that need authentication and ownership checks. The new prototype leaves that source unchanged and isolates one understandable interaction.

What changed

A modern React/Vite frontend, HTTPS URL validation, normalized bounding-box geometry, explicit loading/error states and a cancellable detector adapter. No vendored dependencies are copied into the new source.

What the demo does

It validates a URL and returns a fixed synthetic bounding box. It never fetches the image, recognizes a face, infers an identity or calls Clarifai. The interface labels the result clearly.

Evidence

Four tests passed: insecure/credential URL rejection, valid/invalid geometry, synthetic source labeling and cancellation. The React production build succeeded.

Next engineering work

Review changes in small PRs: dependency cleanup, PostgreSQL migrations, authenticated sessions, ownership checks, password hashing, rate limiting, a server-only provider adapter and full end-to-end regression tests. Legacy account flows and real detection are not implemented in this prototype.
