THE PROBLEM

Turn account evidence into a reviewable queue.

A disabled account can retain a license. Missing sign-in evidence is not proof of inactivity. The evaluator reports what needs investigation and leaves every account unchanged.

Repeatable inputs

An explicit report date and fixture file make results reproducible. The evaluator rejects duplicate IDs, non-boolean account status, invalid thresholds and sign-in dates after the report date.

Human decision

Every row says “Report only.” The adapter makes read-only requests. There are no write calls or automatic license removals. Findings are prompts for review rather than instructions to revoke access.

Six deterministic checks passed, covering normal accounts, combined findings, unknown evidence, the inclusive inactivity threshold, invalid thresholds and missing license evidence.

Graph adapter

The adapter follows validated pagination links, honors bounded Retry-After delays, rejects incomplete snapshots, and pseudonymizes account IDs before returning them. It uses successful sign-in evidence; missing evidence remains a review finding.

23 transport-injected checks cover pagination, throttling, permission errors, untrusted links, repeated pages, malformed responses and the evaluator contract. These tests do not claim live tenant verification.

Before a tenant run

Use an authorized test tenant with the required read permissions, directory role and licensing. Tokens stay in memory, and private exports stay outside the published repository. Consent and a live tenant run remain separate steps.
