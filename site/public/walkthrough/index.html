One record, a second set of eyes.

A short tour of review, correction and the evidence behind the workflow.

This is a synthetic browser-memory sample. Persona switching illustrates permissions; it is not real sign-in.

  1. Open a submission

    As Operator, open sample-002. The owner can inspect it but cannot approve their own work.

  2. Review independently

    Switch to Independent reviewer, reopen sample-002, enter a reason and approve. The approved total changes from 210.25 to 250.25. Inspect the audit snapshots.

  3. Correct and resubmit

    Switch back to Operator and correct the approved record with a reason. It returns to draft and leaves approved totals until reviewed again.

  4. Check the failure path

    The local API tests inject an audit-write failure and verify that the record change rolls back too. The public sample does not call that API.
