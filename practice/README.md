# Optional practice

These are prepared exercises, not a record of completed training. Work at a comfortable pace.

## Explain

Trace a correction from React input through validation to a record/audit transaction. Explain why
display-only token claims cannot authorize an action, and find the stale-version regression test.
Compare the PostgreSQL and SQL Server plans without treating the engines as interchangeable.

## Change

- Add a department filter to the local reporting client/API; consider pagination, invalid input,
  empty results and authorization. Browser filtering is not server-side scoping.
- Add a three-box synthetic sample; verify geometry, result export, clear and cancellation.
- Write a monthly SQL Server report using approved records, explicit date bounds and a small
  expected-results fixture. Explain how correction changes the total.

## Diagnose and repeat

On a local branch, change an expected version or audit-write behavior, run the checks and explain
the failure. Restore correct behavior before publishing. After guided practice, attempt a smaller
variation without step-by-step instructions. Record what you can explain and debug independently. No
deadline, contribution quota or claim of completed independent practice applies.
